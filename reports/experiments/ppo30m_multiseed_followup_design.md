# PPO 30M 多训练种子跟进：冻结设计

本轮从冻结原版 PPO 30M 分别起步，不覆盖旧模型。训练种子为 `994101`、`994202`、`994303`；每个种子配对运行普通起点与危险课程两种已实现方法，各训练 123 个完整事务，即 503808 个环境样本。两种方法沿用原 PPO、课程数据、奖励、KL 参考和网络配置，只改变训练种子。固定预算结束后不自动追加训练。

当前每局 300 万块的六策略评测优先运行。多种子队列在该评测结束前只等待，不争用 8 个 CPU 核心。之后逐一完成可恢复的 GPU 训练；每个事务保存模型、训练器和环境状态并校验哈希。CUDA 不可用时等待恢复，不退回 CPU 训练。

开发评测使用此前未见的 `1420000..1420015`，每局上限 100000 块。同一批种子比较原版 PPO 30M、BC、Hybrid B12、六个新模型与固定规则的传统 V2 Hold。传统 V2 只参与对照，不进行神经网络训练。模型、训练配置、合法动作与正式规则的版本和 SHA256 都保存在 `runs/ppo30m_multiseed_followup/`；逐局结果原子保存，传统 V2 每 10000 块保存可恢复的完整 Core/RNG 状态。

对照同时报告平均存活、P10、真实死亡和右截断、四消占比、正式总分，以及按种子在双方共同存活区间的得分比。原有开发门槛继续适用：四消占比下降不超过 3 个百分点、共同存活得分至少达到 PPO 的 95%、P10 至少达到 PPO 的 95%、平均存活增加至少 1000 块、不得新增低于 10000 块的死亡。16 个开发种子用于观察训练种子差异，不作为独立确认或正式泛化结论。

正式消行得分等于消行基础分乘当前等级，等级随累计消行数上升。因此长寿命模型在后期可积累远大于短寿命模型的总分。此前 300 万块评测在双方共同存活的七个可比较种子上，PPO 累计得分约为 BC 的 1.9 倍；整局总分与共同区间得分必须分别解释。
