# 普通 PPO 微调为何损害 BC：可核验的证据

`20M PPO + BC` 在同一 32 个 validation seeds、20,000 块上限下 32/32 跑满；普通 BC + 2M PPO 为 16/32、平均 15,369 块。中途固定验证也显示波动：约 0.25M 步时 16 局中的 15 局达到 5,000 块上限，约 0.5M 步降为 6/16，约 1M 步为 0/16，约 1.75M 步恢复到 13/16。不同阶段的 5,000/10,000/20,000 上限不可直接比较，表中阶段内使用相同上限的趋势才有意义。

在 BC 原有验证集的 512 个状态上，冻结 BC 与后续 checkpoint 的动作分布对照如下。该状态集**不是**新 30 种子最终测试集。

| 模型 | 与 BC Top-1 动作一致率 | 教师动作准确率 | KL(当前∥BC) | Actor 相对 L2 距离 |
|---|---:|---:|---:|---:|
| 冻结 BC | 100.0% | 93.9% | 0 | 0 |
| 普通 PPO 1M | 54.5% | 55.3% | 8.83 | 0.154 |
| 普通 PPO 2M | 52.3% | 51.6% | 17.58 | 0.188 |

普通 PPO 的 `approx_kl` 是相邻 PPO 策略更新之间的量，任务平均 0.0104、最大 0.109；它小并不代表始终接近最初 BC。`clip_fraction` 平均 0.0617，前 50 个 Task 平均 0.0460，后 50 个为 0.0894。Entropy 从前 50 个 Task 的平均 0.154 增至后 50 个的 0.586。Value loss 从前 50 个 Task 的平均 0.905 增至后 50 个的 21.34，任务最大 127.66。已保留的 TensorBoard Task 中仅找到 3 个 Explained Variance 点，末点为 0.533；它不足以重建全程曲线。

证据支持“普通 PPO 更新使策略远离 BC 且生存受损”。Raw Reward 与长期生存目标偏差、Critic 估计、优化器重置和随机波动都可能参与；现有记录不能给出各原因的独立因果权重。新 KL 实验用冻结概率分布约束漂移，并继续记录实际游戏结果来检验假设。数据复现脚本为 `training/evaluation/bc_ppo_degradation.py`；原始统计在忽略 Git 的 `runs/candidate_bc_next_stage/degradation.json`。
