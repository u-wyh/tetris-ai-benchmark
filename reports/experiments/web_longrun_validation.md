# 网页神经 AI 长局稳定性验证

Seed `12345` 为已使用过的历史功能回归种子。三种 AI 各最多 10000 块；通过后 BC 再最多 100000 块。每一步由网页代码向 8081 发出真实 HTTP 请求，网页按正式 BFS 路径落子，独立 Python Core 从同一 seed 执行返回的 Action ID，并逐步核对完整棋盘、Current、Next、Hold、得分、等级、消行、结束状态及合法动作列表。每 500 块原子提交浏览器/Core 恢复快照与 SHA256 封印，失败即停止。未使用 `1452000..1452031` 或 `1441000..1441031`。

## 资源与恢复

B12 的策略来源：PPO 9945 次，BC 55 次。
- PPO 30M：Node 峰值 RSS 230.8 MiB，8081 服务采样峰值 RSS 688.1 MiB；Node CPU 累计 49.4 秒，服务采样 CPU 最高 68.0%。
- BC Champion：Node 峰值 RSS 229.3 MiB，8081 服务采样峰值 RSS 696.1 MiB；Node CPU 累计 54.8 秒，服务采样 CPU 最高 77.1%。
- Hybrid B12：Node 峰值 RSS 229.5 MiB，8081 服务采样峰值 RSS 712.2 MiB；Node CPU 累计 49.1 秒，服务采样 CPU 最高 84.4%。
- BC 100K：Node 峰值 RSS 288.8 MiB，8081 服务采样峰值 RSS 808.6 MiB；Node CPU 累计 548.4 秒，服务采样 CPU 最高 85.9%。

短窗专门测试另验证：神经 AI 刷新后从网页保存恢复；暂停、继续、切换模式、重开游戏后旧请求不会作用于新棋盘；请求错误停止自动重试并由按钮恢复；服务重启后从 650 块 checkpoint 续跑至 700 块；PPO 与 BC 两个浏览器会话同时各运行 200 块，均逐步通过 Core 校验。静态 8080 服务在测试期间保持可用。

## 结论

若全部封印及回归通过，则本轮在既定历史 seed 和上限内未观察到状态漂移、非法动作或服务故障，具备持续演示条件。结论不扩展为不同 seed 上的模型泛化能力，也不代表触顶后的无限生存。完整原子结果与异常日志在 `runs/web_longrun_validation/`。
