# PPO-Shaped V1 2M：与 PPO-Raw 2M 的配对对照

**结论：**新增洞惩罚大幅减少造洞，但截至 2M 没有提高存活。32 个相同 validation seeds 上，Shaped 平均少活 14.875 块；本轮不扩展至 10M。此报告只比较游戏表现，跨 Reward 版本的训练 Reward 不可直接比较。

## 实验口径

- Shaped run：`ppo_hole_v1_2m_seed42_lambda010`，训练代码 Git `ccebb369776251992b2cf794283dff7c976bebf5`；489 个事务 Task 全部提交，共 2,002,944 步，2026-10-08 17:28（北京时间）完成。Raw 对照取原 run 的同一训练步数 `step_002002944` milestone，均从相同 Step-0 参数开始。
- 唯一训练变量：`reward = raw_reward - 0.10 × max(0, holes_after - holes_before)`；洞按同列中空格上方至少有一个方块计数，落点合并、消行后再数 `holes_after`。Observation、网络、动作空间、Mask、PPO 参数和游戏规则不变。Shaped 的配置、Task 和 worker 状态均记录并校验 Reward 版本与系数。
- 统一评测：validation `100000..100031`，每局上限 5,000 块；两个模型均 `deterministic=True`、使用官方 Action Mask，同一个 TetrisEnv 与游戏分数。每 seed 的数据和配对差异保存在 `runs/ppo_hole_v1_2m_seed42_lambda010/paired_validation_2m.json`。这里没有使用 final-test seeds，也没有按这批结果调系数。

## 学习曲线与风险

相同 16 个 periodic validation seeds 的平均存活：Step-0 两者均 21.5；约 250k 步 Raw/Shaped 为 34.38/15.81，约 1M 为 51.00/33.19，约 2M 为 54.81/40.94。Shaped 有学习进展，但到 2M 仍落后 Raw，未显示更快的学习效率。32-seed 最终评测的平均消行基本相同，平均分数略高，但配对波动不足以据此认定游戏表现更强。

每块造洞减少约 75.6%，说明惩罚确实影响了策略。与此同时，生存缩短，符合“低洞但更易顶出”的可能；所有对局仍通过合法落点结束，不能从这些汇总数据判断模型**有意**快速死亡。由于存活越久可能积累更多负惩罚，快速死亡是该 Reward 的潜在漏洞；本轮结果不能排除它。应进一步看终局高度、动作轨迹与不同训练阶段的配对验证，再决定是否改变系数或设计。当前不启动 10M。

训练期间前期还有其他 CPU 评测并行。Raw 前 489 Task 的训练阶段平均约 530 steps/s，Shaped 约 434 steps/s；Shaped 最后 20 Task 约 522 steps/s，Raw 对应最后 20 Task 约 524 steps/s。洞计数微测约 0.064 CPU 秒 / 4096 次放置，无法解释早期整 Task 约 18% 的平均吞吐差；后期吞吐已接近原基准。训练使用 CUDA 与 8 个 worker，checkpoint retention、validation、milestone 与最终模型均完成。
