# PPO 30M 前瞻搜索失败诊断与 V3 设计

## 冻结对象和证据

PPO 30M SHA256 为 `eb859b8989efe8f3332393ed57110036979b03bb4d3d8d8316d080cf04b2da34`。原 S1/S2、Core、Action Mask、BC/B12 权重和旧评测均未修改。新数据位于 `runs/ppo30m_lookahead_v3/`。旧 seed 990109 仅用于诊断，不进入新开发组。

S1 原决策在 seed 990109 共替换 24 次，24 次搜索动作均立即四消，其中 22 次改变 Hold。逐项评分审计由 `training/evaluation/ppo_lookahead_v3_audit.py` 重放产生，完整公开状态、哈希、概率、排名、正式分数、各评分项、margin 存于 `diagnostics/S1_score_audit_seed_990109.json`。

| 对搜索动作减 PPO 原动作的评分项 | 24 次平均差值 |
|---|---:|
| 归一化即时正式得分 | +1.000 |
| 额外四消奖励 | +2.000 |
| 消行数量奖励 | +0.400 |
| 高度 | +0.010 |
| 凹凸度 | +0.097 |
| 井深 | −0.097 |
| 新洞、总洞、出生区、Game Over | 0.000 |
| PPO log-prob 差 | −0.380 |

得分归一化以 `800 × 动作前等级` 为分母，四消正式分恰好约为 1；上限 1.2 在这些四消动作上没有额外放大。额外 `+2` 四消奖励的量级是正式分的两倍，对总分差贡献 `0.45 × 2 = 0.9`。24 次中，去掉这一项后 17 次不再超过原 0.45 切换门槛。洞、出生区指标对这 24 个根动作没有区分力，井深有时反而轻微偏向 PPO 原动作。

第 2849 块 PPO #383 的概率约 0.639，S1 #249 约 0.361；PPO log-prob 差为 −0.572。S1 的总分差 0.935，超过 0.45；取消额外四消奖励后差值仅 0.035，不会替换。**第 2849 块没有改变 Hold**，所以不能把这次危险动作归因于 Hold 切换。

## 模拟和搜索边界审计

- `simulate_public` 只消费公开 Next；看不见下一块时返回 `phase="unknown"`，不是死亡，也不会查询 Bag/RNG。原 S1 的一层评分对 `unknown` 没有额外处罚。Hold 为空时会多消费一个可见 Next，导致不同根分支剩余可见序列长度不同；S2 每根仍只增加一个可见落子，但信息量可能不同，跨分支未来值不能解释成等深的真实长期预测。
- `public_key` 同时包含棋盘占用、Current、Hold、Next、Hold 可用性、phase、得分和行数；等价公开后继状态合并未发现漏掉 Hold/Next。棋盘只按占用去重，正式物理规则同样只依赖占用，不依赖格子字母。若未来特征使用颜色或来源，须重审此键。
- S2 第二层先按落点 y 和中心距离截取固定 8 个合法动作，再在这 8 个内评分。它并未按完整后继价值选 Beam，可能漏掉真正安全的动作。20K 触发率约 0.8%，与 S1 的存活结果相同，缺少继续加深的证据。
- 深井项为所有列井深之和的上限 4，贡献最多 +0.32，无法明确区分给连续四消保留的通道与无关凹槽；不应把它视为可靠的四消布局保护信号。

## 同快照诊断性消融

从完全相同的第 2849 块 Core 快照与 RNG 出发，首动作和续控策略分开比较，每支最多 1000 块。`A` 去掉额外四消奖励；`B` 在 A 基础上对改变 Hold 增加 0.45 margin 和可见后继检查；`C` 保留旧评分但将 margin 提高到 1.0。A/B/C 在该快照均选择 PPO 原动作 #383，S1 仍选 #249。

| 首动作 | 后续固定 PPO | 后续固定 S1 |
|---|---|---|
| PPO #383 | ≥1000 块，右截断 | ≥1000 块，右截断 |
| S1 #249 | 59 块 Game Over | 59 块 Game Over |

A/B 以各自策略续控且首动作 #383 时也都触及 1000 块上限。不同续控下的得分和四消次数不可混作首动作的单一因果效果；完整分支数据在 `diagnostics/snapshot_ablations_seed_990109_step_2849.json`。这仅证明已知快照中的局部修复，不证明新策略泛化。

## 冻结 V3 候选

- **V3-A**：仍只在 PPO 合法 Top-5 中比较，去掉额外四消奖励，保持原 PPO log-prob 权重、0.45 搜索权重和 0.45 切换门槛，默认 PPO Top-1。
- **V3-B**：在 A 基础上，改变 Hold 的候选额外增加 0.45 margin；必须使可见洞数减少或最高列降低至少两格、保留井深或有明显高度改善，并保留至少一半可见下一块合法动作。该检查只看公开 Current/Hold/Next，不读隐藏 RNG。旧轨迹 22 次 Hold 改写中，有 7 次在去四消奖励后仍过 A 门槛，而在增加 Hold margin 后均不过门槛；因此 B 作为独立待验证候选，而非预设优胜者。

在已知失败状态，A/B 都保留 PPO #383。V3 只用公开一步模拟，未增加搜索深度或 Beam Width。配置与新开发种子在 `runs/ppo30m_lookahead_v3/protocol.json` 冻结；新开发效果必须以独立配对结果判断。

## 新开发种子上出现的 V3-A 回归

seed 991104 的纯 PPO 达到 20K，V3-A 在 2097 块 Game Over。V3-A 全局只替换了两次（第 31、1592 块），都改变 Hold、当步四消；对应搜索总分差分别仅为 0.550、0.492，刚超过 0.45 margin。冻结配置未调整。

对第 1592 块同 Core 快照与 RNG 分支，仅将首动作设为 PPO #1052 或 V3-A #249，分别固定后续 PPO 或 V3-A 控制。两种续控下，#249 分支都在 505 块后 Game Over，#1052 分支都达到 1000 块观察上限（右截断）。这证明该状态中的一次 V3-A 替换具有局部有害作用；不能断言第 31 块替换也有害，更不能把这一个 seed 外推为全部搜索策略。分支原始记录：`runs/ppo30m_lookahead_v3/diagnostics/new_failure_V3A_seed_991104_step_1592.json`。

V3-B 在相同开发 seed 跑满 20K；它阻止了 V3-A 在这局的两次 Hold 改写。与此同时，V3-B 在 PPO 提前死亡的 seed 991103 也于同一 2462 块结束，显示额外门槛可能减少救局机会。20K 配对表见 [V3 对照](ppo30m_lookahead_v3_comparison.md)。
