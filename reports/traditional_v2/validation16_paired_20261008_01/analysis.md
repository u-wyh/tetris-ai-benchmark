# V2 validation 配对分析说明

V2 使用 `v2-1`、增强启发式权重、两层搜索、`beam_width=8`、`lookahead=0.58`，只接收公开 Board、Current、Next 3、Hold、Hold 可用状态和公开计分字段。V1 使用第二阶段已归档的 `v1-adapter-1` 结果；两边的 TetrisCore、动作空间、seed 和 5000 块上限一致，Core/V1 文件自 V1 结果提交后没有改变。

V2 的 16 局全部达到 5000 块上限；V1 有 10 局截断、6 局 Game Over。配对结果中，V2 在这 6 个 V1 提前死亡的 seed 上全部达到上限，没有出现 V1 截断而 V2 提前死亡的 seed。表面上的平均存活差为 955.31 块，bootstrap 95% 区间为 `[324.19, 1680.94]`；非平局的存活胜负为 6 比 0，双侧 sign-test `p=0.03125`。这些统计受 5000 块右截断影响，不能作为无偏最终寿命估计；10 个双截断配对只说明两种策略都至少存活到上限。

V2 平均正式分数为 20,878,968.75，V1 为 16,216,331.25，差为 4,662,637.5。分数差不能单独证明生存能力提升；V2 在许多双截断 seed 上分数反而低于 V1，原因包括不同堆形、Hold 路径和 Hard Drop 距离。消行差为 +386 平均值，主要来自 V2 几乎每局达到约 1999 行的饱和结果。

在同一批公开局面性能采样中，V1 总决策均值约 66.16 ms，V2 约 65.46 ms；V2 的平均策略部分约 60.52 ms，其中未来合法 BFS 约 34.17 ms、模拟和特征约 25.12 ms。正式并行分片记录中，V2 平均决策为 64.40 ms、P95 为 84.69 ms、15.53 次/秒；该值受并行 CPU 负载影响。V2 的端到端速度为 14.49 块/秒。

正式结果仍然饱和。应在相同 seed、相同更高上限下继续比较，才能判断 V2 对最终寿命的收益；本报告不使用 final test seeds 调参，也不把当前 5000 块上限当作真实寿命。

补充的同 seed 高上限开发配对使用 `310100`、`310103` 和 10,000 块：V1 存活 `10000/2388`，V2 存活 `10000/10000`。一对双方都截断，另一对 V1 Game Over 而 V2 截断；样本只有两局，bootstrap 区间为 `[0, 7612]`，sign-test 不显著，因此只能作为方向性验证。原始记录和报告在 `reports/traditional_v2/highcap_paired_dev_20261008/`。
