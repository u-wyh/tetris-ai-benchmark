# Transactional PPO recovery test

- Python tests: 22 passed, including 29 JS/Python Parity subtests; JavaScript regressions: 58 passed.
- Three 1024-step Tasks were trained in a short test. After Task 2 committed at 2048 steps, an incomplete working Task 3 and an orphan committed directory beyond the pointer were injected.
- Resume marked both artifacts abandoned, loaded Task 2's model, optimizer, environment and RNG states, and re-executed Task 3 to 3072 committed steps. Official CSV contained exactly Tasks 1–3, without the injected partial metrics.
- On CPU, the resumed Task 3 policy parameters matched an uninterrupted three-Task run exactly.
- Production transaction experiment uses 4096-step Tasks and targets 32768 committed steps. Its run data lives under ignored `runs/`.
