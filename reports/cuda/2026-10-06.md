# CPU / CUDA MaskablePPO benchmark

- GPU: NVIDIA GeForce RTX 3050 Laptop GPU (4 GiB); driver 595.91.07; `nvidia-smi` CUDA compatibility 13.2.
- Python 3.12.3; PyTorch `2.10.0+cu130` (`torch.version.cuda == 13.0`, CUDA available); SB3 / sb3-contrib 2.9.0.
- Official wheel installed with `.venv/bin/python -m pip install 'torch==2.10.0+cu130' --index-url https://download.pytorch.org/whl/cu130`. The pre-install environment is in `before.txt`.
- Order: CPU, then CUDA. Each ran 16,384 steps, seed 42, one `TetrisEnv`, identical 237-value observation, 1840-action mask, `MlpPolicy` 256/256 Tanh policy and value networks, and the same PPO parameters. Results are in `runs/device_benchmark/{cpu,cuda}/results.json`.

| Metric | CPU | CUDA |
| --- | ---: | ---: |
| Training wall time | 121.94 s | 121.16 s |
| Overall throughput | 134.37 steps/s | 135.22 steps/s |
| Rollout time | 110.73 s | 119.63 s |
| PPO update time | 11.20 s | 1.53 s |
| Environment + mask time | 100.77 s | 100.39 s |
| Mask time (included above) | 67.45 s | 67.19 s |

CUDA improved overall throughput by only 0.64%. Its faster PPO update was almost fully offset by slower rollout/inference; Python TetrisCore and action-mask work dominate total time. **Default for formal training: CPU.** CUDA remains available as an explicit option.

During the CUDA run, 118 `nvidia-smi` samples showed mean/peak GPU utilization 5.28% / 42%, temperature 47 / 49 °C, power 11.04 / 11.85 W, and peak total GPU memory use 202 MiB. No OOM occurred. A CUDA tensor operation was successful and visible as a Python process in `nvidia-smi`. A separate 1,024-step CUDA transactional Task saved and reloaded its checkpoint with model and optimizer tensors on `cuda:0`; config, run metadata and Task metadata all recorded `cuda`.

The two single-run results are indicative rather than a multi-seed speed study. The existing 32,768-step transaction run was left untouched.
